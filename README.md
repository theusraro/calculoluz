# Controle de Energia - Loteamento

Sistema para controle de consumo de energia elétrica de um loteamento em Juiz de Fora.

## Funcionalidades

- Login com usuários
- Cadastro de pessoas/lotes
- Lançamento de leituras mensais
- Edição de leituras
- Cálculo automático de consumo (mês atual - mês anterior)
- Cálculo automático do valor a cobrar
- Tarifa editável
- Modo claro / escuro
- Total geral do loteamento
- **Dados sincronizados no Supabase** (todos os usuários veem as mesmas informações)
